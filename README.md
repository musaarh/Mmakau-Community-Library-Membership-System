# Mmakau Community Library Membership System

A web-based membership application and management system for Mmakau Community Library.

## Purpose

The system will allow community members to:

- Apply for library membership online
- Submit their personal information
- Receive confirmation when their application is received
- Receive an email when their application is approved or rejected

Library staff will be able to:

- Log in securely
- View membership applications
- Search and filter applications
- Review applicant information
- Approve applications
- Reject applications
- Add the library's existing membership barcode after approval
- Notify applicants by email

## Important

The system will **not generate membership barcodes**.

Mmakau Community Library already has its own barcode system. After an application is approved, the librarian will assign an existing library barcode to the member.
